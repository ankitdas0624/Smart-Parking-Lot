The efficient management of parking space is a crucial issue in crowded environments like colleges, offices, cities, and shopping complexes. The traditional methods of managing parking space often rely on manual data entry that causes errors, loss of data, difficulties in keeping track of the vehicles and improper usage of parking space.
This proposed Parking Management System is a program developed under Object-Oriented Programming where automation and simplification of parking process is considered.
In this process, the details of the vehicle, owner, parking slot number, time of entry and time of exit along with the parking cost are kept.
The system will have functionality such as availability of slot, vehicle entry and exit record, search facility for vehicles, payment facility.
This system minimizes the efforts required manually and increases the accuracy.
Through this project, several important OOP concepts such as class, object, encapsulation, inheritance, polymorphism, abstraction, association, multithreading, exception handling  are presented.
The aim of this project is to make the parking system more simple, efficient and effective.
